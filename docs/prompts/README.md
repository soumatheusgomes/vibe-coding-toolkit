# Prompts

To start a project, use [prompt 11](11-next-project-bootstrap.md). To configure or update an existing project, use [prompt 12](12-existing-project-setup.md), with brainstorming, harness and every applicable component. To prepare the machine, use [prompt 10](10-development-environment-setup.md). The others address individual tasks.

| Prompt | Purpose |
|---|---|
| [01 — Sanitation](01-project-sanitation.md) | Measure and organize code |
| [02 — Warnings](02-eslint-warning-burndown.md) | Reduce warnings |
| [03 — Code review](03-multi-agent-code-review.md) | Specialist review |
| [04 — Brainstorm to plan](04-brainstorm-to-plan.md) | Refine a request |
| [05 — Waves](05-parallel-wave-dispatch.md) | Parallel tasks |
| [06 — Memory](06-memory-bootstrap.md) | Persistent context |
| [07 — Complete ESLint](07-eslint-complete-setup.md) | Advanced configuration |
| [08 — Quality gates](08-eslint-quality-gates-install.md) | Copy rules and measure |
| [09 — Large files](09-file-size-refactor.md) | Refactor by responsibility |
| [10 — Machine](10-development-environment-setup.md) | Global environment |
| [11 — Next project](11-next-project-bootstrap.md) | Product and configured foundation |
| [12 — Existing project](12-existing-project-setup.md) | Complete setup, updates, harness and validation |
| [13 — Security review](13-security-review.md) | Read-only repository or diff review with a private evidence-based report |
| [14 — Harness evaluation](14-harness-evaluation.md) | Disposable behavioral checks for agent instructions, recovery and review |
| [15 — Harness improvement](15-harness-improvement.md) | Default native harness workflow for new and existing project setup; optional isolated official CLI lab |
| [16 — Advanced security audit](16-security-audit.md) | Opt-in audit, four private artifacts, remediation batches, and resumable checkpoints |

Prompt 16 is a separate advanced task. Do not run it automatically during machine preparation, onboarding, bootstrap, or existing-project setup. Follow the [security audit usage guide](../08-security-audit.md) when explicitly requested.
